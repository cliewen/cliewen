# CH-113 — Plan truthful brownfield migration

This full plan-revision change establishes P-011 as the migration-only successor campaign. It corrects P-010's former forward reference to simplification: P-011 will make brownfield extraction truthful, while simplification becomes P-012's future door.

The campaign is deliberately `draft` until P-010 closes. It does not implement a second campaign early. Its first milestone changes the protected criterion-identity and evidence contract, so it requires an explicit decision and human acceptance before implementation: imported numeric and opaque identities must be preserved and permanently reserved; migration parity, in-flight work, and operational carriers must be demonstrably retained rather than inferred from the surviving corpus.
