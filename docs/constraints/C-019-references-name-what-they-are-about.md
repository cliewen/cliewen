# C-019 — A reference names what it is about

A report, status, or explanation written for a human or an adopter never leaves a bare `ADR-018` or `CH-008` standing alone: it says in a few words what the record holds, and a status is short and precise rather than a chain of identifiers. This is [ADR-046](../decisions/ADR-046-index-rows-say-what-the-artifact-is-about.md)'s rule — an index row states what its artifact is about rather than only its filename — applied to the surface an index row cannot reach: an agentic review finding, a verification handoff, and an acceptance brief line, none of which is generated by index regeneration.

**Residual:** all of it. `clue validate` reads files and cannot see a review finding, a handoff, or a brief — none of the three is a committed corpus artifact — so no machine will ever hold this. An index row that states only an ID and a reader who learns that something exists and nothing about whether it matters to them fail the same way; saying so here is more honest than naming a promotion trigger that will never fire.
