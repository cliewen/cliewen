# Approve without manual integration commands

The owner wants to approve a reviewed candidate in the conversation and have the agent execute integration and the authorized push. The human decides whether the change is accepted; the agent records and carries out that decision. A changed candidate, base or complete acceptance brief requires a fresh exact approval. No agent fabricates human approval or treats an implementation request as approval of unknown future bytes.
