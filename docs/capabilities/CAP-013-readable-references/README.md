# Readable references

People can understand why a goal, decision, criterion or rule matters from the text they are reading. Agent instructions require relevant meaning inline and descriptive links for optional detail. Human CLI reports add readable local names while keeping canonical identities secondary. Metadata and literal machine-oriented identities retain their existing formats.

See the [proof scenarios](criteria.md) and [presentation design](design.md). Human comprehension remains a human judgment; a passing linter or formatter test does not prove it.
